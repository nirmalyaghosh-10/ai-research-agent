# AI Research Agent

An AI agent that does web research for you.

## What it does
1. Splits your question into 3 smaller searches.
2. Searches the web with Tavily.
3. Writes a short report with source links using Google Gemini.
4. Gives a Trust check: a confidence score and any conflicts between sources.

## Tools used
Python, Tavily API, Google Gemini API, Streamlit
